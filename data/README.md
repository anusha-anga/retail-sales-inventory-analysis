# Data files

Raw data is intentionally excluded from this repository. Download the two source CSVs from [Mendeley Data](https://data.mendeley.com/datasets/27x8mjm8k4/1) and store them locally in this folder if you want to run the SQL templates.

Expected filenames:

- `retail_inventory_ml_apl.csv`
- `retail_sales_ml_apl.csv`

The record is DOI `10.17632/27x8mjm8k4.1`, CC BY 4.0. Preserve source attribution when reusing the data. Do not commit the downloaded CSVs unless you have confirmed the repository's sharing policy and need to redistribute the source files.
